# Rainy attribution

Rainy is an independent desktop application developed by RainyMarks. It is not an official DeepSeek product. The interface primitives under `src/renderer/ui/`, the design tokens under `src/renderer/theme/` that say so, and the other files marked as derived from DeepSeek Harness keep that project's copyright notice and MIT license ([LICENSE.upstream](LICENSE.upstream)). Rainy-specific code uses the PolyForm Strict License 1.0.0 ([LICENSE.Rainy](LICENSE.Rainy), scope in [LICENSE](LICENSE)); those terms do not replace third-party licenses.

The model layer uses [pi-ai and pi-agent-core](https://www.npmjs.com/package/@earendil-works/pi-ai) and the Model Context Protocol SDK under their own licenses. Since 4.0 the Windows application `RainyAgent.exe` is a native Rust program built with GPUI and GPUI Kit (Apache License 2.0); the Rust crates it links and their license texts are appended to the `THIRD_PARTY_NOTICES.md` shipped with the installer. Document previews and the agent's browser run in the Microsoft Edge WebView2 runtime that comes with Windows, loaded through `WebView2Loader.dll` from the Microsoft WebView2 SDK under its BSD-style license, whose text is included there too. The WSL payload includes the official Node.js 22.22.1 Linux x64 distribution, its license and the production dependencies listed in `runtime.json`. Individual dependency directories retain their shipped license/notice files. ripgrep is supplied through the locked `@vscode/ripgrep-linux-x64` package, including its license files.

Rainy adds no official account, telemetry, marketplace or automatic cloud fallback service. The desktop application queries GitHub for stable Rainy releases and downloads core application updates; update checks do not attach project files, chats or model credentials. Model requests go to the endpoint explicitly selected by the user. When web search is on and a DeepSeek model has an API key, the agent's web_search and web_fetch calls send the search terms or page URL to DeepSeek's Search and Fetch APIs with that key; DeepSeek bills them to the user's account. The optional model diagnostic makes a real request to that selected endpoint. Rainy's own updater checks each downloaded installer against the SHA-512 in `latest.yml` and the release's Ed25519 signature before it runs it.

The document previews and the Markdown editor, which the Host serves into WebView2, bundle React, CodeMirror, xterm.js, KaTeX, highlight.js, docx-preview (Apache License 2.0), Milkdown Crepe 7.22.3 (MIT, the rich Markdown editor), Mermaid 12.2.0 (MIT, diagrams in Markdown) with the ELK layout engine elkjs 0.9.3 (Eclipse Public License 2.0, used unmodified; its source is available at https://github.com/kieler/elkjs and in the `elkjs` npm package), SheetJS Community Edition 0.20.3 (Apache License 2.0, from the SheetJS CDN), JSZip (MIT), the Hanken Grotesk and Geist Mono fonts (SIL Open Font License 1.1, through `@fontsource-variable`) and their dependencies; the build writes their full license and notice texts to `dist/renderer/THIRD_PARTY_NOTICES.txt`. Runtime dependency directories retain Pyright, TypeScript Language Server, TypeScript, Prettier, tsx and their notices. The [IDE source definition](toolpacks/ide-tools.sources.json) records debugpy, js-debug and Ruff downloads and digests; their accompanying licenses remain under `resources/ide`. The standalone js-debug distribution receives a local `package.json` declaring its CommonJS module format. The offline Ubuntu development packages retain their packaged copyright files; `resources/ide/system-packages/manifest.json` records their versions, hashes and APT index evidence.

The PDF viewer uses [pdf.js](https://github.com/mozilla/pdf.js) 2.16.105 (`pdfjs-dist`), whose two browser files ship in `resources/pdfjs/` with its Apache License 2.0 text, together with its character maps (`cmaps/`, Adobe's license in `cmaps/LICENSE`) and standard fonts (`standard_fonts/`: Foxit fonts under `LICENSE_FOXIT`, Liberation fonts under the SIL Open Font License in `LICENSE_LIBERATION`).

## Strata local runtime

Rainy 3.x offered the Strata component as a download; 4.0 does not offer it yet. The component carries [Niko1221/Strata 0.1.39](https://github.com/Niko1221/Strata/releases/tag/v0.1.39) under its MIT license, together with CPython 3.12.14 from the pinned python-build-standalone input. The [runtime source manifest](toolpacks/strata-runtime.sources.json) records the upstream revision, selected files, dependency versions and SHA-256 values. The packaged `resources/strata-runtime/THIRD_PARTY_NOTICES.txt` and `licenses/` directory retain the Strata, Python, llama.cpp/gguf, embedded engine and Python dependency notices.

The Windows x64 engine targets NVIDIA CUDA 13; the package includes the required CUDA Runtime and cuBLAS DLLs with their NVIDIA license texts. A compatible NVIDIA driver, version 580 or newer, remains a user prerequisite. Compiled GPU targets are `sm75`, `sm86`, `sm89`, and `sm120`; this distribution does not supply an AMD or Linux inference engine. It does not install a display driver.

The runtime contains no main or MTP model weights and no derived dense/expert model packs. Users supply the supported main GGUF shards and matching MTP GGUF or prepared runtime directory. Small upstream routing metadata and token-ID subsets remain with their source attribution. Rainy performs local preparation only after an explicit start request; model preparation does not download weights, reuse a developer's model paths, or select a cloud service. The user's model files remain subject to their own terms.

## Offline environment

The offline environment media include Microsoft WSL and the Ubuntu WSL image from the recorded Microsoft and Ubuntu release locations. Their upstream license and notice files remain with the corresponding distributions. `runtime/environment/media-verification.json` records the environment download locations and digests. These records identify the packaged components and do not make a licensing determination.
