# RainyAgent attribution

RainyAgent is an independent desktop composition of DeepSeek Harness 0.1.7-rc.2 at upstream commit `477b4f420553e8a52c2fbccc464d7561b239c443`. It retains upstream copyright notices and their MIT license. RainyAgent-specific code uses the source-available terms in LICENSE; these terms do not replace upstream or third-party licenses. The source repository includes the original upstream sources and licenses. RainyAgent is not an official DeepSeek desktop distribution.

The Windows carrier uses Electron. Its distribution includes `LICENSE.electron.txt` and `LICENSES.chromium.html`. The WSL payload includes the official Node.js 22.22.1 Linux x64 distribution, its license, the pinned Pi model adapter and the production dependencies listed in `runtime.json`. Individual dependency directories retain their shipped license/notice files. ripgrep is supplied through the locked `@vscode/ripgrep-linux-x64` package, including its license files. Native DSH helpers are built from the matching upstream source in this repository.

RainyAgent adds no official account, telemetry, marketplace or automatic cloud fallback service. The desktop carrier queries GitHub for stable RainyAgent releases and downloads core application updates; update checks do not attach project files, chats or model credentials. Model requests go to the endpoint explicitly selected by the user. The optional model diagnostic makes a real request to that selected endpoint. `electron-updater` performs release discovery, installer download and integrity checks under its existing license.

The embedded IDE bundles Monaco/VS Code editor components and monaco-languageclient with their pinned compatible versions. `resources/editor/THIRD_PARTY_NOTICES.txt` retains the full license and notice texts for the dependencies included by the editor build. Runtime dependency directories retain Pyright, TypeScript Language Server, TypeScript, Prettier, tsx and their notices. The [IDE source definition](toolpacks/ide-tools.sources.json) records debugpy, js-debug and Ruff downloads and digests; their accompanying licenses remain under `resources/ide`. The standalone js-debug distribution receives a local `package.json` declaring its CommonJS module format. The offline Ubuntu development packages retain their packaged copyright files; `resources/ide/system-packages/manifest.json` records their versions, hashes and APT index evidence.

The CTF workbench includes IceSky by spindriftpapilio, pinned to commit `e0321b41ade55b288466203c68fad96ab6c18455` from [its repository](https://github.com/spindriftpapilio/icesky). Its source and bundled browser dependencies are under `resources/icesky/`; [the integration patch](resources/icesky/RAINY_PATCH.md) records one local change. The project maintainer has confirmed authorization from IceSky's author for public redistribution with RainyAgent. The upstream repository did not contain a license file at the pinned revision; this separately confirmed authorization is not a relicensing of IceSky or its dependencies under RainyAgent's source-available terms. Original author attribution and bundled dependency licenses remain with the distribution.

## Strata local runtime

The core installer bundles [Niko1221/Strata 0.1.39](https://github.com/Niko1221/Strata/releases/tag/v0.1.39) under its MIT license, together with CPython 3.12.14 from the pinned python-build-standalone input. The [runtime source manifest](toolpacks/strata-runtime.sources.json) records the upstream revision, selected files, dependency versions and SHA-256 values. The packaged `resources/strata-runtime/THIRD_PARTY_NOTICES.txt` and `licenses/` directory retain the Strata, Python, llama.cpp/gguf, embedded engine and Python dependency notices.

The Windows x64 engine targets NVIDIA CUDA 13; the package includes the required CUDA Runtime and cuBLAS DLLs with their NVIDIA license texts. A compatible NVIDIA driver, version 580 or newer, remains a user prerequisite. Compiled GPU targets are `sm75`, `sm86`, `sm89`, and `sm120`; this distribution does not supply an AMD or Linux inference engine. It does not install a display driver.

The runtime contains no main or MTP model weights and no derived dense/expert model packs. Users supply the supported main GGUF shards and matching MTP GGUF or prepared runtime directory. Small upstream routing metadata and token-ID subsets remain with their source attribution. RainyAgent performs local preparation only after an explicit start request; model preparation does not download weights, reuse a developer's model paths, or select a cloud service. The user's model files remain subject to their own terms.

## Native tools and offline environment

Misc includes 7-Zip, ExifTool, Wireshark, Binwalk, FFmpeg, Audacity, StegSolve, PNGcheck, QRazyBox, ImageLSBViewer, ImageMagick, WinMerge, Qalculate!, Sonic Visualiser, Tesseract OCR, SoX, TweakPNG, multimon-ng, GNU strings, GIMP, SQLite, DB Browser for SQLite, qpdf, ripgrep and pcapfix. Reverse includes IDA, x64dbg/x32dbg, Detect It Easy, ImHex, JADX, dnSpy and PyInstaller Extractor. The [source definition](toolpacks/native-tools.sources.json) records each distribution, acquisition location and version evidence; the generated package inventory records file hashes. Each component retains its own copyright and applicable terms in its accompanying notices. RainyAgent's license covers its own integration code.

Yakit 1.4.8-0919 comes from the [official Windows release](https://github.com/yaklang/yakit/releases/tag/v1.4.8-0919) and retains its unmodified [GNU Affero General Public License version 3](https://github.com/yaklang/yakit/blob/v1.4.8-0919/LICENSE.md). That release includes Yak engine 1.4.8-beta19 in `bins/yak.zip`; the embedded executable hash matches the [official engine release](https://github.com/yaklang/yaklang/releases/tag/1.4.8-beta19). Yakit's bundled Electron and Chromium notices remain with its application files. The package does not run Yakit's installer or modify its application archive.

curl, jq, yq, SQLite, DB Browser for SQLite, qpdf, ripgrep, Bruno and pcapfix use pinned upstream downloads. Other selected tool distributions come from the supplied local collection. The source definition records supplemental license notices and private runtime files separately. The homepage and About credit, `Develop by NCUCyberBase`, identifies this desktop integration and does not replace upstream copyright or license notices.

The offline environment media include Microsoft WSL and the Ubuntu WSL image from the recorded Microsoft and Ubuntu release locations. Shared Windows dependencies include Eclipse Temurin JRE 21.0.12.1+1 and Microsoft .NET 8 runtime archives; dnSpy 6.6.0 carries .NET Desktop 10.0.9. IDA's private Python 3.12.14 comes from a pinned python-build-standalone archive with pinned PyQt5-sip and zombie-imp wheels; its original IDAPython files and upstream terms remain with IDA. multimon-ng 1.6.1 comes from the publisher's Windows x64 release and carries its GPL notice alongside private SoX conversion files. Their upstream license and notice files remain with the corresponding distributions. `runtime/environment/media-verification.json` records the environment download locations and digests, while the native-tool source definition records shared-runtime versions and acquisition paths. These records identify the packaged components and do not make a licensing determination.
