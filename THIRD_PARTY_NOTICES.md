# Rainy attribution

Rainy is an independent desktop application developed by RainyMarks. It is not an official DeepSeek product. The interface primitives under `src/renderer/ui/`, the design tokens under `src/renderer/theme/` that say so, and the other files marked as derived from DeepSeek Harness keep that project's copyright notice and MIT license ([LICENSE.upstream](LICENSE.upstream)). Rainy-specific code uses the PolyForm Strict License 1.0.0 ([LICENSE.Rainy](LICENSE.Rainy), scope in [LICENSE](LICENSE)); those terms do not replace third-party licenses.

The Windows application `RainyAgent.exe` is a native Rust program built with GPUI and GPUI Kit (Apache License 2.0), and since 4.1 the Host, `rainy-host` for Windows and Linux, is a Rust program as well; Rainy contains no Node.js. Its model requests and agent loop are Rainy's own, written after the behavior of [pi-ai and pi-agent-core](https://www.npmjs.com/package/@earendil-works/pi-ai) (MIT), which earlier versions used. The Rust crates both programs link and their license texts are appended to the `THIRD_PARTY_NOTICES.md` shipped with the installer. Document previews and the agent's browser run in the Microsoft Edge WebView2 runtime that comes with Windows, loaded through `WebView2Loader.dll` from the Microsoft WebView2 SDK under its BSD-style license, whose text is included there too. Text search uses ripgrep's directory walker (`ignore`, Unlicense or MIT) and the `regex` crate (MIT or Apache License 2.0), linked into the Host.

The agent's per-model guidance ([Per-model agent adaptation](docs/model-adaptation.md)) adapts text from the model instructions of [OpenAI Codex](https://github.com/openai/codex) and the core mandates of [Gemini CLI](https://github.com/google-gemini/gemini-cli), both Copyright their authors under the Apache License 2.0; the `apply_patch` tool implements Codex's patch format, its Lark grammar and its tool descriptions, and the plan tools take Codex's `update_plan` and Gemini CLI's `write_todos` arguments. The Rainy versions are modified: shortened, rewritten for Rainy's tools and combined with Anthropic's published prompting guidance for Claude.

Rainy adds no official account, telemetry, marketplace or automatic cloud fallback service. The desktop application queries GitHub for stable Rainy releases and downloads core application updates; update checks do not attach project files, chats or model credentials. Model requests go to the endpoint explicitly selected by the user. When web search is on and a DeepSeek model has an API key, the agent's web_search and web_fetch calls send the search terms or page URL to DeepSeek's Search and Fetch APIs with that key; DeepSeek bills them to the user's account. The optional model diagnostic makes a real request to that selected endpoint. Rainy's own updater checks each downloaded installer against the SHA-512 in `latest.yml` and the release's Ed25519 signature before it runs it.

The document previews and the Markdown editor, which the Host serves into WebView2, bundle React, react-markdown, KaTeX, highlight.js, docx-preview (Apache License 2.0), Milkdown Crepe 7.22.3 (MIT, the rich Markdown editor, with CodeMirror for its code blocks), Mermaid 12.2.0 (MIT, diagrams in Markdown) with the ELK layout engine elkjs 0.9.3 (Eclipse Public License 2.0, used unmodified; its source is available at https://github.com/kieler/elkjs and in the `elkjs` npm package), SheetJS Community Edition 0.20.3 (Apache License 2.0, from the SheetJS CDN), JSZip (MIT), the Hanken Grotesk and Geist Mono fonts (SIL Open Font License 1.1, through `@fontsource-variable`) and their dependencies; the build writes their full license and notice texts to `dist/renderer/THIRD_PARTY_NOTICES.txt`. The [IDE source definition](toolpacks/ide-tools.sources.json) records the downloads and digests of the editor tools Rainy offers for Windows and Linux: Ruff 0.16.9 and ty 0.0.85 (MIT), TypeScript 7.0.2's native compiler (Apache License 2.0), debugpy 1.8.22 (MIT) and js-debug 1.140.0 (MIT); on Windows they are the downloadable components `ide-python` and `ide-web`, which carry their licenses, and the Linux runtime keeps them with their licenses under `resources/ide`. The standalone js-debug distribution receives a local `package.json` declaring its CommonJS module format. The offline Ubuntu development packages retain their packaged copyright files; `resources/ide/system-packages/manifest.json` records their versions, hashes and APT index evidence.

The PDF viewer uses [pdf.js](https://github.com/mozilla/pdf.js) 2.16.105 (`pdfjs-dist`), whose two browser files ship in `resources/pdfjs/` with its Apache License 2.0 text, together with its character maps (`cmaps/`, Adobe's license in `cmaps/LICENSE`) and standard fonts (`standard_fonts/`: Foxit fonts under `LICENSE_FOXIT`, Liberation fonts under the SIL Open Font License in `LICENSE_LIBERATION`).

## Strata local models

Rainy does not ship or redistribute Strata. Settings → Tools downloads [Niko1221/Strata](https://github.com/Niko1221/Strata) (MIT license) from that project's own GitHub releases when the user asks for it, checks it against the release's install manifest, GitHub's digest and Strata's signed feed, and lets Strata's own updater install its inference engine and later updates. Strata's components, including any GPU runtime libraries, come with Strata's own license and notice files. Models are downloaded from Hugging Face or ModelScope at the user's request under their publishers' licenses; Rainy distributes no model weights.

Rainy 4.1 to 4.2 offered a Strata 0.1.39 runtime component built from pinned inputs; 4.3 no longer offers it, and its files can be deleted from the Strata card.

## Offline environment

The offline environment media include Microsoft WSL and the Ubuntu WSL image from the recorded Microsoft and Ubuntu release locations. Their upstream license and notice files remain with the corresponding distributions. `runtime/environment/media-verification.json` records the environment download locations and digests. These records identify the packaged components and do not make a licensing determination.
