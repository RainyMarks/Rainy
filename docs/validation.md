### 改动

- **用 JSON 导入 MCP 服务器**（合并自 `mcp-json` 分支）：设置 → Skills 与 MCP 的“从 JSON 导入”读取各家应用的 MCP 配置和服务器页面上的片段，预览时隐藏密钥，只导入勾选的；Host 在服务器以 4xx 拒绝 Streamable HTTP 时改用旧版 HTTP+SSE。
- **挂载盘上的文件夹**：Windows 上 `fs.promises.realpath` 通过 GetFinalPathNameByHandle 取卷的盘符名，挂载管理器不认识的卷（火眼等取证工具挂载的镜像、内存盘、部分虚拟盘）上会以 EISDIR 或 ENOENT 失败，添加项目时报“所选路径不是文件夹”。新的 `src/host/realpath.ts` 在原生调用失败但路径确实存在时，改用 Node 的 JavaScript 逐级解析，再不行用 `resolve` 的结果；Host 里所有用到 realpath 的地方都换成它。
- **窗口拖动**：以前每次用户移动窗口（`moved`）都执行为显示器变化准备的“整体放回工作区”，窗口拖出屏幕一部分就被拉回、跳到别处（用户录屏可见）。现在用户移动后只让最小尺寸跟随所在显示器，只有任何显示器都看不到标题栏时才移回（`gripArea`，与恢复上次窗口位置共用）。
- **资源管理器集成（3.9.1 复查的 4 项）**：Rainy 没有登记的部分不做删除（因此只开右键菜单时，Windows 为“选择其他应用”写的 `Applications\RainyAgent.exe` 不会被删）；打开“打开方式”前就存在的 `Applications\RainyAgent.exe`，关闭时只删 Rainy 加的 `FriendlyAppName` 和 `SupportedTypes`；“原有键”记录和“哪些部分查过”在写注册表之前保存；没有记录的部分（3.9.0 留下的）只删 Rainy 自己的键和值，上层键一律保留；开关写注册表失败时，设置恢复为原来的值。
