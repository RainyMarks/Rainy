## 3.0.0（2026-10-15）

被测产物为 `Rainy-3.0.0-windows-x64-setup.exe`（173,969,995 字节，SHA-256 `817fb5a4d8f86fe1e29241d758352c95ae22eddcd30c43657c84f47e766ae20e`），构建自提交 `a1e4c15ac4`；之后的提交只修改 README 截图和本验收记录。Linux 运行环境分片为 280,199,468 字节（SHA-256 `d2385aa3994a4ff67e71eb0c07cb4ef8bd467a738504c8e81f23f9f56997db26`），WSL 和 SSH 共用；PHP 分片与 2.5.0 相同。

### 改动

- 移除 CTF 功能：原生工具目录与工具包（下载、更新、签名通道、`--rainy-install-tools`、安装器里的工具部分）、AI 安全工具箱 IceSky、IDA MCP 预设、图片的颜色通道与位平面视图、十六进制视图的内嵌文件扫描和 PNG 尾部数据提示。PDF 查看器使用的 pdf.js 改为放在 `resources/pdfjs`，由 Host 在 `/rainy/pdfjs/` 提供。旧版本留在安装目录 `tools` 中的文件不删除。
- SSH 远程开发：执行目标新增 `ssh`（`src/main/ssh.ts`、`SshHostTransport`）。Host 通过 Windows 自带的 OpenSSH 客户端在服务器上启动，控制通道是会话的标准输入输出，Host 端口用 `ssh -L` 转发到本机同一端口。远程命令只有一段固定的单引号加载器，其余内容全部用 base64 传递，sh、bash、zsh、fish 和 csh 都能正确读取。`install-runtime.py` 新增 `--fetch`（服务器按分片从 `v3.0.0-resources` 下载、逐片校验、可续传，一分钟后低于 256 KiB/s 视为太慢）和 `--receive`（从标准输入接收电脑上传的归档）；旧 Python 没有 `data` 过滤器时手动检查归档条目。
- SSH 的提问：ssh 把内置的 node.exe 当作 askpass 程序，`NODE_OPTIONS` 预加载的小脚本通过命名管道询问 Rainy（`ssh-askpass.ts`）；新主机的指纹在 Rainy 的对话框里确认，密码和口令在 Rainy 的小窗口里输入，只在本次运行的内存中保留；同一连接重复询问时视为上次答案错误，重新询问。
- 设置 → 运行环境新增“SSH 远程开发”卡片（列出 `~/.ssh/config` 中的主机和在 Rainy 中添加的主机，添加前先连接一次检查登录、Linux x86_64 和 python3），命令面板新增“连接到 SSH 主机…”。状态栏显示执行目标名称；模型提示词会说明命令在 SSH 服务器上运行。在 SSH 主机上不提供 Windows 文件夹选择框、不映射拖入的本机文件，Strata 连接会说明服务器访问不到本机模型。
- 设置里失败操作的提示去掉了 Electron 的 “Error invoking remote method …” 前缀；英文搜索结果数使用正确的单复数。

### 检查

- **测试**：本机 Windows 11 上 Vitest 94 个文件 718 项通过（10 项按平台跳过），node:test 35 项通过（2 项跳过）；`install-runtime.py` 的 4 项 Linux 测试（含本地 HTTP 分片下载和标准输入接收）在 WSL Ubuntu 中通过。新增的 askpass 测试用真实的 node 进程和命名管道验证还原问题文字、记住答案和拒绝伪造的令牌。Ubuntu 24.04 与 Windows 2022 CI 均通过（[运行记录](https://github.com/RainyMarks/Rainy/actions/runs/38713889821)）。
- **SSH 远程开发**：在 WSL 中以普通用户运行一个独立的 OpenSSH 10.2 服务端（端口 22022，单独的 HOME，只接受测试密钥），打包程序用带口令的测试密钥连接：
  - 首次连接时口令窗口只出现一次，安装和启动两次连接都使用同一答案。服务器自行从 GitHub 下载并校验运行环境，约 56 秒进入工作台；网络中断的一次（SSL EOF）自动改为由电脑下载后上传，约 2.5 分钟进入工作台。已安装后再次启动，运行环境检查约 0.8 秒、Host 约 0.6 秒就绪。

- **安装包内容**：7-Zip 解开后 8,734 个文件与 `release/win-unpacked` 逐一一致（2.5.0 为 9,334 个）。
- **试运行**：用临时用户数据启动，约 5.4 秒显示工作台。名称为 Rainy、版本为 3.0.0，工具目录相关的桥接已不存在，可选组件为 Strata 和 PHP，页面错误为零，关闭窗口后进程全部退出。

### 改动

- 项目地图：Host 新增 `map/`，用 ripgrep 列出项目文件（遵守 `.gitignore`），统计行数，跟踪常见语言的 import，从清单文件和 import 认出技术栈，把第三方、生成和压缩过的文件排除在代码之外（`map.get`，结果缓存 20 秒）。界面有“架构”（分层方框和依赖线，一屏最多 16 个部分）和“文件”（按行数的方块）两种视图；“AI 讲解”请求一次对话模型，结果存在 `maps/` 下（`map.explain`）。
- 审查 AI 的修改：`chat.changes` 列出对话中 AI 改过、还没保留或撤销的文件及增删行数，`chat.changeBase` 给出改动前后的文本，`chat.keep` 在对话文件里追加 `review` 行（2.4 之前的版本读取时跳过）。输入框上方列出改动；编辑器审查时每处改动旁有保留和撤销，审查栏可以跳转、全部保留或全部撤销。
