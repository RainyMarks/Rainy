# RainyAgent 验收记录

本记录对应 2026-10-05 的 RainyAgent 1.0.0 发布验收，区分源码检查、确定性模拟服务、打包程序和真实模型推理。发行文件的大小、SHA-256、构建提交和最终验收结果随 [v1.0.0 Release](https://github.com/RainyMarks/RainyAgent/releases/tag/v1.0.0) 提供；旧版本的 API 对照与性能数字不作为本版本结论。

## 源码与回归

独立源码目录已通过锁文件离线安装与完整源码构建。真实 Git 检出保留符号链接和可执行文件模式；477 个固定 IceSky 资源逐项哈希一致，IDE 资源和 Strata 清单验证通过。固定二进制及需保留原始字节的文本资源使用精确路径的 Git 属性，避免检出时改变校验值。

本轮针对退出清理、环境切换与退出竞争、草稿保存失败、快速打开搜索乱序与失败、空模型 ID 的发现请求、更新状态机、Strata 生命周期及本地模型连接补充了回归。Strata 连接由当前 Host 独立核对服务身份、已加载模型和实际上下文；上下文缩小时保留用户输出配置，必要的修改需要明确确认。测试包括不正确的服务、未加载模型、请求密钥要求、远端地址及配置未被失败请求覆盖。

相关检查入口为桌面目录的 Vitest 配置、`packages/client/ui-rainy/tests`，以及 [Rainy CI](../../.github/workflows/rainy.yml)。发布标签对应的源码已通过 [Ubuntu 24.04 与 Windows 2022 CI](https://github.com/RainyMarks/RainyAgent/actions/runs/37405776590)，在普通 runner 上构建源码并执行指定回归，不依赖上游组织的内部 runner。

## 离线资源与自包含运行时

23 个原始离线输入共 13,563,886,456 字节，封装为 30 个最大 1 GiB 的传输分片。实际 PowerShell 重组已完成，23 个文件的大小和 SHA-256 全部一致；缺片、损坏及路径校验由 [传输测试](tests/release-assets.test.mjs) 覆盖。构建准备入口在独立目录中恢复了 IDE、Windows 基础组件、WSL 组件目录和 Strata 运行时。

Strata 0.1.39 与 Python 3.12.14 的运行时包含 1,702 个文件，共 846,093,650 字节。将归档解压至包含中文和空格的不同目录后，隔离 Python 的解释器、导入模块和搜索路径均来自该运行时；引擎、服务和离线准备工具的入口检查通过。此次验收没有借用开发机的 Strata 安装或个人 Python 环境。

运行时不包含主模型 GGUF、MTP 权重或派生 dense/expert 文件。用户必须自行选择兼容主模型及匹配的 MTP 来源。NVIDIA 驱动与硬件仍属于系统要求；没有随包提供 AMD 或 Linux 推理引擎。

## 桌面与本地服务

Windows x64 最终打包程序使用隔离用户数据启动。应用全局版本和通用设置版本均为 1.0.0；真实 Monaco 编辑器、中文项目、未保存文本和无激活入口检查通过。Strata 原生接口报告随包运行时可用、模型未配置，不会自动加载模型。首页 [工作区截图](assets/workbench.png) 来自该程序实际界面。

[桌面验收入口](tests/installed-ui.mjs) 的首次启动和重启验收均通过，编辑恢复与设置检查无页面或控制台错误。[Strata 桌面入口](tests/strata-desktop.mjs) 从真实界面保存本地端口、连接并核对 Host 和界面模型设置，再点击诊断获得流式文本 `RainyAgent connected`。关闭应用后，外部服务仍保持运行。mock 没有配置工具调用返回，因此未将工具调用记为通过；这些结果不代表实际 GPU 推理能力、工具使用能力或生成质量。

最终程序的 Windows 与 WSL Host 启动、项目往返、草稿和选择状态恢复通过，两个环境中各执行一项 JavaScript 和 Python 程序，均正常退出并输出预期的 `42`。Python 使用明确指定的随包 Windows 解释器和 Ubuntu 解释器，未据此验证默认解释器发现。

## 自动更新与发行完整性

更新控制器回归覆盖检查、下载、错误、销毁和用户确认流程。真实 Electron [更新下载测试](tests/update-download.mjs) 使用公开 updater API、临时用户数据、回环 HTTP 服务和最终 1,191,900,440 字节安装器，验证同版本不下载、旧版本完整下载并通过 SHA-256/SHA-512 校验，以及错误 SHA-512 被拒绝。该测试不执行更新安装。NSIS 内 28,127 个文件的压缩完整性检查通过，关键文件摘要与被测程序一致。

生产程序保留资源清单签名和 Electron ASAR 完整性检查。Windows Authenticode 证书未配置，因此系统可能显示未知发布者；资源签名不能代替 Windows 发布者签名。常规退出不会自动安装下载的更新；确认重启安装后仍须完成草稿保存和 Host 清理。

[托管 Windows 2022 安装验收](https://github.com/RainyMarks/RainyAgent/actions/runs/37409614050) 下载并核对同一份最终安装器，在临时虚拟机上完成当前用户静默核心安装、注册项与两个快捷方式检查、真实界面启动、1.0.0 版本及无激活入口检查、正常关闭和静默卸载。页面及控制台错误均为零；卸载移除了核心程序、注册项和快捷方式，并保留三个位置的用户文件。该任务未安装可选工具分卷、模型权重或 WSL，也未执行跨版本升级。

## 验收范围

本轮没有加载大型真实模型；真实 Strata GPU 推理、吞吐量、长上下文能力及不同显卡兼容性尚未验证。

打包程序测试使用隔离用户数据，并保留已有应用安装、项目及模型配置。交互式 UAC、系统组件启用、重启恢复和跨版本更新安装仍需独立测试；Release 附带的 `VALIDATION.json` 区分各项检查的执行环境和实际结果。

WSL NAT 下的 Windows 回环服务可达性取决于网络模式。应用在所选 Host 上检查连接并报告失败，不更改防火墙、监听地址或系统网络配置，也不自动切换至云模型。没有本轮真实在线供应商调用，因此不据此声明任何在线模型性能变化。

## 1.0.2 常用工具环境检查

38 个 Windows 常用工具按新来源清单重新制备，共 22,542 个文件、5,187,367,870 字节；打包为两个原始分卷并验证 SHA-256。静态 Windows 导入依赖检查未发现缺失 DLL。27 项使用自有文本、图像、音频、PDF、PCAP 和托管程序集的离线功能检查通过；CyberChef、QRazyBox、Image LSB Viewer 的三项浏览器检查通过，未产生外部请求。IceSky 人工工具相关的 53 项无密钥测试通过。这些检查没有向第三方目标发送探测请求。

IDA 7.7 的隔离配置使用包内 Python 3.12.14、匹配的 SIP 绑定及 `imp` 兼容模块。两个无界面入口均完成本地脚本并得到 `42`，加载的 Python DLL 仅为工具目录里的 `python3.dll` 和 `python312.dll`，没有使用另一套 IDA 的 Python 3.11 注册设置。隔离图形入口到达首次许可确认页；本轮未替用户确认许可，故未将确认后的完整 GUI 操作列为通过。其余 GUI 工具的逐项交互也不由命令行和静态依赖检查代替。

StegSolve 与 JADX 使用随工具包提供的 Temurin Java 21.0.12.1；dnSpy 6.6.0 使用包内 .NET Desktop 10.0.9。原生工具启动环境去掉继承的 Python、Java、.NET、Qt 等覆盖和第三方 PATH，仅保留包内路径与 Windows 系统路径。签名工具频道的第 2 次修订与本地目录、安装元数据、两个分卷及源码输入清单使用同一个工具包标识；新的工具分片固定到 1.0.2 资源存档，其余未变化的离线构建输入固定到 1.0.0 资源存档。源码恢复已按 23 个 SHA-256 固定输入完成，并展开 IDE、Strata 与 Windows 基础组件。

Windows Host 从官方 SHA-256 校验后的 Node ZIP 使用 Windows 自带 .NET ZIP 解压器展开。隔离解压两次分别用约 27 秒和 26 秒恢复 2,313 个文件；提取的 `node.exe` 报告 `v22.22.1`。随后完整暂存脚本生成 403 个包、26,342 个文件、712,789,571 字节的 Windows Host，正常退出。这项结果验证的是 Host 暂存，尚不等同于 1.0.2 NSIS 安装和卸载验收。
